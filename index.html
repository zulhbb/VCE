Integrasi Google Sheets & GitHub Pages

Semua tempahan akan masuk terus ke Google Sheet & kerusi disegerakkan secara automatik.

💡 Tip untuk GitHub Pages: Anda juga boleh menampal URL exec terus ke dalam pembolehubah DEFAULT_GOOGLE_SCRIPT_URL di dalam kod index.html supaya semua pengunjung automatik tersambung ke Google Sheet yang sama.

Langkah Setup Mudah (3 Minit):
  1. Buka Google Sheets baharu di Google Drive anda.
  2. Klik menu Extensions → Apps Script.
  3. Padam kod sedia ada di dalam Code.gs dan Tampal (Paste) kod di bawah, kemudian tekan ikon Save (💾).
  4. Klik butang biru Deploy → New deployment di penjuru atas kanan.
  5. Pilih jenis Web app:
    • Execute as: Me (Email anda)
    • Who has access: Anyone (Sangat Penting!)
  6. Klik Deploy, berikan kebenaran akses (*Authorize access*), dan salin Web app URL (https://script.google.com/macros/s/.../exec) ke dalam kotak di atas!
  7. (Pilihan) Jika anda mahu buka terus dari Apps Script tanpa GitHub, buat fail HTML bernama Index.html di dalam Apps Script dan tampal keseluruhan kod laman web ini.
